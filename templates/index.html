What happens to your image

1

Input checks

The file must decode as a valid image format (PNG, JPEG, BMP).

2

Preprocessing

The image is resized to 224 × 224 and normalized via integrated MobileNetV2 scaling.

3

MobileNetV2 classifier

MobileNetV2 transfer learning with ImageNet weights, predicting true softmax class probabilities.

Test accuracy 94.39%, Macro F1 0.9431
4

Grad-CAM visualization

Grad-CAM highlights image regions that influenced the model's prediction. This visualization is an attribution aid, not a verified tumor location.

Evaluated on 1,195 held-out test images, achieving 94.39% accuracy and a macro F1-score of 0.9431. Evaluation was performed using an image-level split; patient-level independence has not been established. Performance on external clinical datasets may differ.

Trained on the Brain Tumor MRI Dataset (Masoud Nickparvar, CC BY 4.0), evaluated on a duplicate-aware split; image-level evaluation on one public dataset; performance on other scanners or hospitals is unknown.
